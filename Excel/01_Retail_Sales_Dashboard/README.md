# Retail Sales Dashboard – Excel

## Project Overview
This project focuses on analyzing retail sales data and creating an interactive-style dashboard using Microsoft Excel.

The dashboard provides insights into sales performance across different regions, product categories, months, and payment methods.

## Dataset Information
- **Dataset:** Retail Sales Practice Dataset
- **Records:** 500 rows
- **Columns:** 11
- **Period:** January–December 2025
- **Tool:** Microsoft Excel 2007

### Dataset Columns
Order ID, Order Date, Region, City, Category, Product, Quantity, Unit Price, Sales, Profit, and Payment Mode.

## Data Validation
Before building the dashboard, the dataset was checked for:
- Duplicate Order IDs
- Blank or missing values
- Valid date entries
- Correct numeric data types

No duplicate Order IDs or blank cells were found.

## Key Performance Indicators (KPIs)
The dashboard includes six KPIs:

1. Total Sales
2. Total Profit
3. Total Orders
4. Total Quantity Sold
5. Average Order Value
6. Profit Margin

## Analysis Performed
Five PivotTable analyses were created:

1. Sales by Region
2. Sales by Category
3. Monthly Sales by Category
4. Sales by Payment Mode
5. Top 5 Products by Sales

## Dashboard Visualizations
The dashboard contains five charts:

- Clustered Column Chart – Sales by Region
- Horizontal Bar Chart – Sales by Category
- Line Chart – Monthly Sales Trend by Category
- Doughnut Chart – Sales Distribution by Payment Mode
- Horizontal Bar Chart – Top 5 Products by Sales

## Key Business Insights
- West region recorded the highest sales.
- Electronics contributed the largest share of total sales.
- August recorded the highest monthly sales.
- Net Banking was the highest-contributing payment mode.
- Laptop was the top-selling product by sales value.
